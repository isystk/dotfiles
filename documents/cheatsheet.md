## 完全コマンドリファレンス

### 1. エディタ操作 (Neovim & IdeaVim 共通)

標準的なVim操作をベースにしつつ、Windowsのショートカットや挿入モードでの利便性を高める設定。

| 分類             | キー操作                    | 内容 / 挙動                                           |
|----------------|-------------------------|---------------------------------------------------|
| **Windows風**   | `Ctrl + a`              | **全選択** (ノーマルモード)                                 |
|                | `Ctrl + z` / `Ctrl + y` | **元に戻す (Undo)** / **やり直し (Redo)** ※挿入モード可         |
|                | `Ctrl + c` / `Ctrl + x` | コピー / 切り取り (ビジュアルモード)                             |
|                | `Ctrl + v`              | 貼り付け (挿入モードでもペースト可能)                              |
| **カーソル移動**     | `h/j/k/l`               | 上下左右に移動                                           |
|                | `gg` / `G`              | ファイルの最上端 / 最下端へ移動                                 |
|                | `Ctrl + u/d`            | 半画面分 上にスクロール / 下にスクロール                            |
|                | `Ctrl + h/j/k/l`        | **挿入モードのまま** 上下左右に移動                              |
|                | `Ctrl + a` / `e`        | **挿入モードのまま** 行頭 / 行末へ移動 (Emacs風)                  |
|                | `Tab`                   | 対応するカッコ `()` `{}` `[]` `<>` へのジャンプ                |
| **単語移動**       | `w` / `b`               | 次の単語の先頭 / 前の単語の先頭へ移動                              |
|                | `e` / `ge`              | 単語の末尾 / 前の単語の末尾へ移動                                |
| **行内ジャンプ**     | `f [文字]` / `t [文字]`     | 指定文字まで右へジャンプ / その手前へジャンプ                          |
|                | `0` / `^` / `$`         | 行頭 / 行の最初の文字 / 行末へ移動                              |
| **検索・選択**      | `*` / `#`               | カーソル下の単語を次検索 / 前検索                                |
|                | `Tab` (選択中)             | 選択範囲を右へインデント（**選択状態を維持**）                         |
| **置換**         | `:%s/A/B/g`             | ファイル全体の A を B に一括置換                               |
|                | `:%s/A/B/gc`            | 確認しながら一括置換                                        |
| **テキストオブジェクト** | `ciw` / `diw` / `viw`   | **単語内**を消して挿入 / 削除 / 選択 (Inner Word)              |
| (範囲指定)         | `ci"` / `ci(` / `cit`   | **"..."内** / **(...)内** / **HTMLタグ内** を書き換え       |
|                | `ca"` / `ca(` / `cat`   | 囲み記号（" や ( や タグ）を**含めて**書き換え                      |
| **繰り返し操作**  | `.` (ピリオド)              | 直前の編集を繰り返す: 文字の削除・変更などを再実行 |
| **マクロ (記録)**   | `q[a-z]`                | **録画開始**: `qa` でレジスタ `a` に記録開始（左下に「Recording」と表示） |
|                | `q`                     | **録画終了**: 記録中に `q` を押すと保存                         |
| **マクロ (再生)**   | `@[a-z]`                | **録画再生**: `@a` でレジスタ `a` に記録した操作を実行               |
|                | `@@`                    | **直前のマクロを再実行**: 連続して使う場合に便利                       |
|                | `[数字]@[a-z]`            | **回数指定実行**: `10@a` で一気に10回繰り返す                    |

### 2. IdeaVim 特有・IDE 連携操作

PHPStorm の強力な解析機能や Git 連携を Vim キーで呼び出すための設定。

| 分類           | キー操作              | 内容 / 挙動                                   |
|--------------|-------------------|-------------------------------------------|
| **コードジャンプ**  | `Space + d` / `i` | **定義元**へジャンプ / **実装先**（インターフェースの実装等）へジャンプ |
|              | `Space + u` / `r` | **使用箇所**をクイック表示 / 使用箇所を検索パネルで一覧表示         |
|              | `Space + v`       | **Laravel ビュー**の使用箇所を表示 (Laravel Idea)    |
| **リファクタ**    | `Space + n`       | **変数・クラス名のリネーム** (Name)                   |
|              | `Space + a`       | **クイックフィックス** (Action / Alt + Enter 同等)   |
|              | `Space + f`       | **コード自動整形** (Format)                      |
|              | `Space + c`       | **選択範囲のケースを切り替える** (StringManipulation)   |
| **IDE画面操作**  | `Space + q`       | クリックリストを開く                                |
|              | `Space + e` / `s` | プロジェクトツリー(Explorer) / メソッド一覧(Structure)   |
|              | `Space + z`       | **集中モード(Zen)** の切り替え（一括非表示）               |
|              | `Space + b`       | プロジェクトツリー上の現在のファイルを表示                     |
| **git 連携**   | `Space + j` / `k` | Git の変更箇所（差分）へ 次(Next) / 前(Prev)          |
|              | `Space + g`       | カーソル位置のGit Blame情報を表示                     |
| 補完           | `Ctrl + n / p`    | 挿入モード中、IDE 標準の補完ウィンドウを表示                  |
| 引数操作         | `caa` / `daa`     | 関数の引数を削除して入力モードへ / 引数を削除                  |
| 囲み(Surround) | `cs"'` / `ds"`    | 外側の `"` を `'` に変更 / 外側の `"` を削除           |
|              | `ysiw"`           | 単語を `"` で囲む                               |
| 設定管理         | `Space + ev`      | `.ideavimrc` を開いて編集する (Edit)              |
|              | `Space + sv`      | `.ideavimrc` をリロードして即時反映** (Source)       |

### 3. Git 操作 (git [コマンド])

`.gitconfig` のエイリアス。日常的なソース管理を爆速にします。

| 分類        | コマンド                 | 内容 / 元の命令                         |
|-----------|----------------------|-----------------------------------|
| **基本操作**  | `st` / `ad`          | 状態確認 / ステージング                     |
|           | `ca` / `cr`          | 直前コミット修正 / 作成者・日時を現在に更新して修正       |
|           | `cm`                 | **【AI】** 差分からメッセージを生成しVimで編集      |
|           | `co` / `cb`          | ブランチ切替 / 新規ブランチ作成                 |
|           | `bd` / `bv`          | ブランチ削除 / ブランチ情報表示（追跡先含む）          |
|           | `sa`                 | 未追跡・無視ファイルも含め全スタッシュ               |
|           | `rmc`                | Gitの管理対象から除外する                    |
| **同期**    | `up`                 | 同期,up,最新の取得と再配置 (`pull --rebase`) |
|           | `pu`                 | 初回プッシュと追跡設定 (`push -u origin`)    |
| **確認・ログ** | `ll` / `ls`          | **グラフ付き詳細ログ** / 統計付き1行ログ          |
|           | `lu` / `lf`          | 作成者でログを検索 / ファイル名でログを検索           |
|           | `ba` / `br`          | 全ブランチ表示 / リモートのみ表示                |
|           | `ta` / `tr`          | 全タグ表示 / リモートタグのみ表示                |
|           | `ranking` / `-all`   | 今月のコミット数ランキング / 全期間ランキング (著者別) |
| **差分・修正** | `di` / `dn`          | 差分表示 / 差分のあるファイル名のみ表示             |
|           | `d1` 〜 `d5`          | 直近 1 〜 5 つ前のコミットとの比較              |
|           | `r1` 〜 `r5`          | 直近 1 〜 5 つのコミットを `rebase -i`      |
|           | `edit` / `-unmerged` | 変更あり（または衝突中）ファイルを一括Vim展開          |
|           | `resolve-conflict`   | **【AI】** Claude Code を使ってGitコンフリクトを自動解消  |
|           | `archive-diff`       | 比較元との差分をZIP化（納品用等）                |

### 4. Shell & OS 操作 (zsh)

`.zshrc` の操作。

| 分類              | コマンド / キー                         | 内容 / 実行例                                            |
|-----------------|-----------------------------------|-----------------------------------------------------|
| **ディレクトリ**      | `ll` / `...` / `....`             | 詳細リスト表示 / 2階層上へ / 3階層上へ                             |
|                 | `[dir]` / `cd [dir]`              | ディレクトリ名のみで移動 / **【enhancd】** 曖昧検索移動                 |
| **編集・AI**       | `vi` / `nvim-ide`                 | Neovim起動 / パネル展開モードでNeovim起動                   |
|                 | `history`                         | 日時付き履歴表示                                          |
| **比較**          | `diff` / `zdiff`                  | 標準的な差分表示 / zip内ファイルの差分表示                            |
| **出力・連携**       | **`copy`**                        | コマンドの結果をクリップボードへコピー<br/>例：`echo "text" \| copy`     |
|                 | **`open`**                        | ブラウザで指定したURLを開く<br/>例：`open https://www.google.com` |
|                 | **`explorer`**                    | エクスプローラーで指定したURLを開く<br/>例：`explorer .`             |
| **キー操作**        | `Ctrl + r`                        | 履歴からコマンドを検索                                         |
|                 | `Tab` / `→`                       | 強力な入力補完 / オートサジェストを確定                               |

### 5. 独自スクリプト (run [コマンド])

AI 連携や GitHub CLI のラッパー機能。

| 分類               | コマンド                | 内容 / 実行例                                                  |
|------------------|---------------------|-----------------------------------------------------------|
| **AI ツール**       | `gen-pr`            | 差分から PR 説明文を自動生成                                          |
|                  | `gen-readme`        | GithubのREADMEを自動生成                                        |
|                  | `gen-blog`          | マークダウン形式で記事を生成                                            |
|                  | `gen-blog-thumbnail` | ブログ記事タイトルからアイキャッチ画像を生成<br/>例：`run gen-blog-thumbnail 'タイトル' out.png`  |
|                  | `gen-marp`          | Marpスライドやプレゼン原稿を自動生成・変換します。                               |
|                  | `gen-voice`         | マークダウンから音声ファイルを生成します。                                     |
|                  | `gen-video`         | PDFと音声ファイルを組み合わせて動画を生成します。                                |
|                  | `audio-transcribe`  | 音声ファイルの文字起こし（`file-task.sh`を利用）<br/>例：`run audio-transcribe meets.mp3`  |
| **GitHub 操作**    | `github`            | Github PRを選択して操作(ブラウザで開く、チェックアウト、マージ、AIレビュー)              |
| **Docker 操作**    | `docker`            | 実行中のコンテナ一覧から選択して操作(コンテナに入る、 ログ / 詳細情報 / 変更差分 の確認、再起動、 削除) |
|                  | `docker prune`      | 未使用のイメージ、コンテナ、ボリュームを確認してから削除                              |
| **MySQL 操作**     | `mysql`             | MySQLデータベースに接続して操作(ログイン、インポート、エクスポート)                     |
|                  | `mysql query`       | MySQLデータベースに指定のSQLを実行                                     |
| **WordPress 操作** | `wordpress`         | WordPressサイトの管理(投稿一覧、ブラウザで開く、削除、カテゴリー一覧)                  |
| **ファイル操作**   | `web-screenshot`    | Webページを画像ファイルに変換します。                                    |
|                  | `images-to-pdf`     | 画像ファイルをPDFに変換します。                                          |
|                  | `pdf-to-images`     | PDFファイルを画像ファイルに変換します。                                          |
|                  | `cleanup`           | 不要なメタデータファイル（Zone.Identifierと.DS_Store）を一括削除              | 
|                  | `find-crlf`         | CRLFファイルを検索、確後後にLFに変換                                     |
| **開発エディタ設定**   | `vscode backup / restore`     | VSCodeの設定ファイルをバックアップ / リストア          |
|                  | `antigravity backup / restore`     | Antigravityの設定ファイルをバックアップ / リストア          |
